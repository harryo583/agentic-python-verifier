Steps to run and evaluate this project

1. Install Python dependencies.

   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt

2. Run deterministic offline tests.

   pytest tests/ -m "not integration"

   These tests do not require an Anthropic API key or TLA+ tools. They mock the
   LLM boundary and use local TLC-output fixtures.

3. Install TLA+ tools for real TLC checks.

   Download tla2tools.jar from the official TLA+ tools release and set:

   export TLA2TOOLS_JAR=/absolute/path/to/tla2tools.jar

   The older TLA_TLC_JAR environment variable is also accepted.

4. Configure Anthropic for live end-to-end runs.

   export ANTHROPIC_API_KEY=sk-ant-...

   The default model is configured in src/config.py and can be overridden with
   ANTHROPIC_MODEL or the CLI --model option.

5. Run a finite benchmark prompt.

   python -m src.main "$(cat examples/bounded_counter.txt)" -o generated/bounded_counter

   Other small prompts live in examples/. Live outcomes are model-dependent and
   may incur API costs, so they should not be treated as deterministic
   benchmark pass rates.

6. Inspect generated artifacts.

   Verified TLA+ modules are written under generated/<case>/tla/.
   Refined Python modules are written under generated/<case>/python/.
   Per-iteration TLC scratch files and reports are written under
   generated/<case>/work/<slug>_iter<N>/.

   Useful per-iteration reports include proposal.json, proof_bundle.json,
   iteration_summary.md, and, when repair was requested, repair.json and
   repair_summary.md.

7. Interpret the proof scope correctly.

   The project is finite-domain inductive checking with TLC. Invariants must
   enumerate finite memberships for state variables so TLC can use Inv as an
   initial predicate for consecution and property checks. The system does not
   claim unbounded TLAPS proofs or deterministic live LLM success rates.

8. Read the final report.

   The final course report is in final_report/main.tex. If LaTeX is installed,
   build it from final_report/ with:

   pdflatex -interaction=nonstopmode -halt-on-error main.tex
   bibtex main
   pdflatex -interaction=nonstopmode -halt-on-error main.tex
   pdflatex -interaction=nonstopmode -halt-on-error main.tex
